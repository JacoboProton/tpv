# Architectural Decision Records (ADRs)

This directory contains ADRs documenting key architectural choices for the **TPV** project.

- **0001-monolith-vs-micro-frontends.md** – Decision between a single‑page monolithic application and a micro‑frontend architecture.
- **0002-supabase-vs-websocket.md** – Choice of Supabase real‑time layer versus a custom WebSocket implementation.
- **0003-drizzle-vs-prisma.md** – Evaluation of Drizzle ORM against Prisma for database access.
